Cómo usar la pizarra

Lápiz: curvas suaves con estabilización ajustable. Aumenta «Suavidad» para reducir las pequeñas vibraciones del pulso.

Seleccionar: pulsa una fórmula o imagen para moverla. Arrastra sus esquinas para cambiar el tamaño manteniendo sus proporciones, o usa los controles − / + y el porcentaje. Puedes volver a seleccionarla en cualquier momento.

Escuadra: activa el ajuste a 0°, 45° y 90° con lápiz o resaltador. También puedes mantener Shift.

Pluma: haz clic para vértices rectos; arrastra al crear un punto para curvas Bézier. Enter termina. «Cerrar» une el último punto al primero. Escape cancela. Ctrl+Z elimina el último punto.

Imágenes: pega con Ctrl+V, carga un archivo o arrástralo a la pizarra. Mueve la imagen, ajusta su tamaño y pulsa «Colocar». Luego escribe encima.

Deshacer: Ctrl+Z / Cmd+Z. El borrador borra trazos; conserva las imágenes y las fórmulas.
